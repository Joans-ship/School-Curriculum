# Day 3 — Conditionals & Events: "If This… Then That!"
**Theme:** If something happens — do something!
 
## 🎯 Learning Objectives
By the end of Day 3, kids should be able to:
- Explain what a conditional is using the "if-then" structure
- Follow and create conditional rules using LEGO bricks as triggers
- Distinguish between a condition being TRUE vs FALSE
- Apply if-then logic in a Blockly activity
---
 
## 10:00–10:15 | Recap Game — "I Know a Loop"
 
Pass a LEGO brick while music (or clapping rhythm) plays. When it stops, the holder must say:
- "A loop is…"
- "My loop pattern yesterday was…"
- "A loop in real life is…"
Then show a quick stacked pattern and ask: "Is this a loop? What is the repeating unit? How many times does it repeat?"

## 10:15–10:35 | Quick Game — "Robot Rules!" (Intro to Conditionals)
 
**Movement game — IF/THEN Simon Says:**
 
The facilitator calls out conditions. Kids only act if the condition is true:
- "IF I say 'banana' → spin around."
- "IF I clap twice → jump."
- "IF I say 'dance' → freeze!"
Let kids take turns being the caller and inventing their own IF-THEN rules.
 
**Debrief:**
- "Why did you only move when the condition was true?"
- "What happens when the condition is FALSE?" *(nothing — the computer skips it)*
> "This is exactly how computers think. They check a condition — is it true or false? If true, they act. If false, they do nothing, or they do something else."

## 10:45–11:10 | LEGO Challenge — "Top Brick Rules"
 
This activity makes conditionals physical. The top brick of a stack is the **condition**. The group's **reaction** is the action.
 
**Setup:** Each group has a set of rule cards (printed or written on the board):
- IF top brick is RED → everyone says "Stop!"
- IF top brick is BLUE → everyone stands up
- IF top brick is YELLOW → clap three times
- IF top brick is GREEN → say "Go go go!"
**How it works:**
 
### Round 1 — Follow the Rules
1. One child builds a secret stack of 4–5 bricks without showing the group.
2. They place it in the middle. Everyone looks at the **top brick only**.
3. The group reads the rule card and performs the action for that colour.
4. The child then removes the top brick. New top brick → new condition → new reaction.
5. Repeat until the stack is gone.
**Facilitator question after each reveal:**
> "Was the condition TRUE or FALSE? What made you act?"
 
### Round 2 — Write Your Own Rules
Each group writes 3 new IF-THEN rules using the colours they have. They swap rule cards with another group and play Round 1 using the other team's rules.
 
This is the moment kids go from *following* conditionals to *creating* them — the same shift as going from reading code to writing it.
 
**Key vocabulary to introduce:**
- **Condition:** the thing you're checking (is the top brick red?)
- **True / False:** the result of checking it
- **Action:** what happens when the condition is true

**Introduce events briefly:**
> "A condition is something you check. An event is something that *triggers* the check — like a button press, a key press, or a crash. The event fires → the condition is checked → the action runs."
 
Ask: "Can you think of an event in real life that triggers a chain of decisions?" *(alarm goes off → IF you're tired → snooze. IF you're late → jump up!)*

## 11:30–11:45 | Blockly Activity — If-Then Builder
 
**What the activity should look like:**
 
Kids open the If-Then Builder. On the right side of the screen is an interactive **traffic light** — 3 (later 5) coloured bulbs they can click. The workspace has one type of block: **"IF light is [colour] → [reaction]"** where the reaction is chosen from a dropdown (STOP, SLOW DOWN, GO, HONK, DANCE, FREEZE, etc.).
 
There are 4 levels:
- **Level 1:** Code one rule — IF red → STOP. Click the red light to test it. The screen shows a reaction. The other lights do nothing because no rule exists for them yet.
- **Level 2:** Code two rules — IF red → STOP, IF green → GO. Test both. The computer picks the right reaction automatically depending on which light is clicked.
- **Level 3:** Code all three lights. Every colour has a rule. Full traffic light logic.
- **Level 4:** Free mode — 5 lights including orange and pink. Kids invent their own funny reactions (IF pink → DANCE, IF orange → SPIN). They test all rules and explain each one to the group.
The key teaching moment: when a kid clicks a light that has no rule coded, the screen shows *"No rule for this colour — the computer does nothing."* This makes the TRUE/FALSE distinction completely visible.
 
**Facilitator prompt:**
> "What happens when the condition is false? What does the computer do? Why is that useful?"
